# web2remotion 阶段一实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 创建 `web2remotion` 阶段一项目，提供 15 个 Recordly 风格 SVG 特效预览、自然语言 Prompt 映射和可验证的效果目录，但不实现整体成片逻辑。

**Architecture:** 项目把效果定义集中在 `effect-catalog/effects.json`，由脚本校验定义并生成独立 SVG 与总览页。`.codex/skills/web2remotion` 提供给未来 Codex 的两阶段工作流：先生成/确认效果或剪辑表，确认后才执行；本阶段只交付效果目录。

**Tech Stack:** Node.js ESM、内置 `node:test`、SVG、Markdown、Codex Skill frontmatter；不引入 PixiJS，不接入 Playwright 或 Remotion 合成入口。

**Spec:** `docs/superpowers/specs/2026-08-17-web2remotion-stage1-design.md`

## Global Constraints

- 项目目标目录必须是 `G:\\claude_project\\code-agent\\web2remotion`。
- 阶段一只实现效果原型、SVG、Prompt 映射和目录校验。
- 不实现完整 GitHub 录制、telemetry、剪辑表执行、最终 MP4 或 GIF。
- 每个效果必须有唯一 ID、中文名称、关键词、Prompt 示例、默认参数和独立 SVG。
- SVG 必须是内联图形，不依赖远程资源。
- Skill 名称必须是 `web2remotion`，description 必须以 `Use when...` 开头。
